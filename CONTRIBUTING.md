# Contributing

ARGUS is a private research and portfolio project; external pull requests are
closed (see the README's Contributing section). This document exists for the
author and for AI coding assistants working in this repository.

## Agent rules

`.agents/rules/` holds tool-neutral standing instructions consulted by AI
coding assistants working in this repo:

- `code-review.md` — code review checklist and standards.
- `commenting-standards.md` — when and how to comment code.
- `quant-prompt-engineering.md` — principles for designing and evaluating LLM
  prompts used by the quantitative agents (`argus/agents/`).
- `readme-generation.md` — standards for writing or updating the README.

## Known limitations

The README's "What to Know Before Trusting Output" section is the current,
honestly-stated list of gaps in this system.
